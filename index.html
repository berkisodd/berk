A bit more

Nearly all of this is one HTML file. No build step, no npm install, nothing to set up. You open it and it works. Partly that's taste, partly it's because I got tired of fighting tooling when I just wanted to make the thing.

The part I get stuck on is usually how something feels. Whether a menu slides in from the right or the left, how long a button takes to respond, holding to delete instead of an "are you sure?" popup. Small stuff, but it's the difference between an app you tolerate and one you like using.

Mostly plain JavaScript and CSS. I'll pick up whatever the project needs. That's how I ended up learning Canvas, Web Audio, and service workers.
